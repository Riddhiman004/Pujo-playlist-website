# 🪔 Pujo Playlist 🎵

>  Pujo. Your Vibe. Your Playlist

Pujo Playlist is a festive, Durga Puja themed music website created to bring the atmosphere of **Sharodiya Pujo** together with music.

The website features a beautiful Puja-inspired visual experience with Durga Puja, dhak, crowd and pandal visuals, along with two curated music sections:

- 🪔 **OG OLD GOLD** — Timeless Pujo classics
- 💃 **NEW DANCE PUJO** — Modern and energetic Pujo beats

Both playlists are powered by **Spotify**.

---

## ✨ Features

- 🪔 Beautiful Durga Puja themed homepage
- 🎨 Traditional red & gold visual design
- 🥁 Durga Puja, dhak and crowd themed background
- 🎵 Spotify playlist integration
- 🪔 OG OLD GOLD playlist
- 💃 NEW DANCE PUJO playlist
- 🎧 Embedded Spotify music player
- 🔙 Smooth "Back to Pujo" navigation
- ✨ Animated floating Pujo-inspired elements
- 📱 Fully responsive design
- 💻 Works on desktop, tablet and mobile

🎧 Spotify Integration

The playlists are embedded using Spotify's official embed player.

The playlist URLs can be changed inside:

script.js

Example:

oldGold: {
    title: "OLD GOLD",
    spotify:
        "https://open.spotify.com/embed/playlist/YOUR_PLAYLIST_ID"
}

and:

newDance: {
    title: "NEW DANCE PUJO",
    spotify:
        "https://open.spotify.com/embed/playlist/YOUR_PLAYLIST_ID"
}
