# 🪔 Pujo Playlist 🎵

> **Your Pujo. Your Vibe. Your Playlist.**

A Durga Puja themed music website with curated Spotify playlists, a festive visual experience, responsive layout, and a persistent mini Spotify player.

## ✨ Features

- 🪔 Durga Puja themed homepage
- 🥁 Durga idol, dhak and crowd cover artwork
- 🎵 OG OLD GOLD Spotify playlist
- 💃 NEW DANCE PUJO Spotify playlist
- 🎧 Embedded Spotify player
- 🎵 Persistent mini Spotify player
- 🔙 Back to Pujo navigation
- ✨ Animated floating decorations
- 📱 Responsive design
- 💻 Pure HTML, CSS and JavaScript
- 🚀 Static-site ready for GitHub Pages, Netlify, Vercel, etc.

## 🚀 Run locally

Open `index.html` directly or use VS Code + Live Server.

## 🌐 Deploy

This is a static website and can be deployed to GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

For GitHub Pages:
1. Push the project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Choose the branch you want to deploy.
4. Save and open the generated Pages URL.

## 🛠️ Customize

- Change the cover: replace `assets/images/puja-bg.png`.
- Change colors/layout: edit `style.css`.
- Change playlists/interactions: edit `script.js`.
